# 人工叙事验收脚本

真实 API 测试未获授权，尚未执行。这里不是模型文案质量通过报告。

在新建的独立验收存档中，对三个供应商分别使用以下输入，记录原文、provider/model、日期、缺陷与纠错分支，不要求三家的文字相同：

1. 让沈彻进来。
2. 今夜先不谈军务。你这几日睡得可还好？
3. 第三镇先复核，不预先认定是谁虚报。明日再查。
4. （心里想：有些秘密还不能告诉任何人。）
5. 我不接受这样的接触，先把手放下。
6. OOC：减少解释性旁白，多用对白和停顿。
7. 与同一人平静交谈十轮，检查仍是同一夜、天气连续、没有重复吃醋与固定数值奖励。
8. 召见顾青崖，问他知道些什么，检查他不知道无人转告的私下谈话。
9. 写信给拓跋野，检查不会瞬移，寄出不等于收到。
10. 翻回三月二十八日，查看当时快照；在分享秘密之前分叉，继续问这件事，检查旧未来隔离。

人工检查：玄天华是否始终保留发言、动作、心理和同意权；六人声音是否可辨；是否允许拒绝、调停、延后；是否有合理后果；是否误将计划或怀疑当成事实。程序启发式只能拦截部分问题。
